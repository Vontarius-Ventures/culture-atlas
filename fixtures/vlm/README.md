# VLM fixtures

Structured `VlmAnalysis` outputs (see `packages/providers/src/vlm/types.ts`) for the spec's VLM boundary cases: clear, blurred, ambiguous (competing subjects), multicultural, logo-free and adversarial text. They drive the compiler tests through `FakeVlm`; they are not model recordings. Reference names that look like brands use the `Fixture` prefix.
