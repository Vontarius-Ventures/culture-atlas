## Shared content-plan seam

from style/connection-topics.ts:

```
{ key, subjectId, claim, sourceCue, tagQuery, requiresDocumentary }
```

All fields are bounded; key/query are closed static taxonomy, claim is the
original active DiscoveryClaim, sourceCue is conservative public appearance/topic
language. Compiler owns `documentaryPlansFor()` and passes an optional
`topicPlan` admission constraint, intersecting existing permitted subjects/tags.
Content proof retains original claim and exact excerpt, plus optional sourceCue,
topicPlanKey and kind (`documentary` or `topic_film`). A narrative film must use
an actual candidate topic tag, never a fake documentary tag.
