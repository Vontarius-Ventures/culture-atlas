# Sample imagery: sources and licenses

Every image the consumer app ships for "Try an example" and the sample discovery feed is listed here. No mockup screenshots are shipped, and no image shows a real person's likeness or a real brand logo.

## Current set: original illustrations (project-owned)

The build environment could not reach Wikimedia Commons (`commons.wikimedia.org` and `upload.wikimedia.org` were refused by the network egress policy), so no third-party photographs were downloaded. Instead, every image below is an original illustration drawn in code by `fixtures/images/generate-illustrations.ts`. The SVG scenes are rendered to JPEG with sharp. The design guide allows this: "generate standalone replacements that preserve each image's composition".

- **Author:** culture atlas contributors (generated by `generate-illustrations.ts`, deterministic)
- **License:** same license as this repository's source code (the user chooses it at release). No third-party rights are involved.
- **Source:** this repository. Regenerate with `pnpm exec tsx fixtures/images/generate-illustrations.ts`.

The taste questionnaire (spec amendment 2.2) reuses twelve of these illustrations as its image picks (`fixtures/onboarding/catalog.json`, `image.license: "project-original"`). Each stands for real Qloo tags resolved by `scripts/build-onboarding-catalog.ts`; the illustration does not claim to depict them.

Use the photos above as `display_metadata.image.url` (for example `/samples/feed/tea-rituals.jpg`) with `license: "project-original"` when seeding sample discovery items. Artists and films have no image, so the UI renders its text treatment. Never substitute a picture of a real performer or a film still without a license.

## Replacing them with public-domain / CC0 photographs

When Wikimedia Commons is reachable, `fixtures/images/fetch-commons.ts` can search Commons for files that are public domain or CC0 only. It does this with the `haslicense:unrestricted` search keyword, then re-checks each file's `LicenseShortName` in its extmetadata and rejects anything that is not public domain or CC0. It downloads a 1200 px rendition into `apps/web/public/samples/commons/` and appends each file's title, author, license and source URL to the table below. Review every downloaded image before use: check that it shows no identifiable people, logos or watermarks. Then point the sample items at the new paths.
